📦 Level 1: What is the First-In, First-Out (FIFO) Rule?

A Queue is a linear data structure that restricts data access according to the First-In, First-Out (FIFO) principle. The element that enters the queue first is guaranteed to be the element removed first. Think of a conveyor belt at a shipping factory or a line of people buying movie tickets—the first package placed on the belt reaches the shipping truck first!

REAR (Ingestion / Enqueue)

New items are added to the back of the queue (REAR pointer). It takes O(1) constant time.

FRONT (Exit Bay / Dequeue)

Items are removed strictly from the front (FRONT pointer). Trying to remove items from the middle violates FIFO!

// JavaScript FIFO Implementation
class Queue {
  constructor() { this.items = []; }
  enqueue(item) { this.items.push(item); } // Add at Rear
  dequeue()      { return this.items.shift(); } // Remove at Front
  peek()         { return this.items[0]; } // Inspect Front
}

🎟️ Level 2: Queue Operations & Boundary Safety

In fixed-capacity queues (like arrays with fixed memory limits), operations must check boundary states to prevent crashes, buffer overflows, and memory leak vulnerabilities.

➕ Enqueue(item)

Inserts a new element at the REAR pointer. Fails if the queue is full.

Complexity: O(1)
🎟️ Dequeue()

Removes and returns the element at the FRONT pointer. Fails if empty.

Complexity: O(1)
🔍 Peek()

Inspects the FRONT element without mutating or removing it.

Complexity: O(1)
⚠️ Overflow Exception

Occurs when calling Enqueue() on a queue that has reached max capacity (size === capacity).

⚠️ Underflow Exception

Occurs when calling Dequeue() on an empty queue (size === 0).

🚦 Level 3: Queue Implementation Variants

Standard queues can be adapted to overcome array memory fragmentation or handle urgent priority scheduling.

🔄 1. Circular Queue (Ring Buffer)

In linear array queues, dequeuing leaves wasted empty slots at the front. A Circular Queue connects the last memory slot back to the first using modulo wrap-around arithmetic:

🚨 2. Priority Queue

Elements carry a priority level. High-priority items (e.g. Ambulances or OS interrupts) jump ahead of lower-priority items, overriding standard FIFO arrival order!

  • Hospital ER Triage (Ambulances served before routine checkups)
  • CPU Task Interrupt Handling
  • Dijkstra's Shortest Path Algorithm (using Min-Heap)

🚂 Level 4: Double-Ended Queue (Deque)

A Deque (pronounced "deck") is a generalized linear data structure allowing element insertion and removal from BOTH the FRONT and REAR pointers in O(1) constant time.

1. addFirst(item)

Inserts element at FRONT (Left gate).

2. addLast(item)

Inserts element at REAR (Right gate).

3. removeFirst()

Unlinks element from FRONT pointer.

4. removeLast()

Unlinks element from REAR pointer.

Versatility: Queue + Stack Hybrid

Because Deques allow operation at both ends, they can function as a FIFO Queue (insert Rear, remove Front) or a LIFO Stack (insert Front, remove Front). Common in text editor Undo/Redo buffers and Sliding Window Maximum algorithms.
