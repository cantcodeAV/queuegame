💡 Double-Ended Queue (Deque) Concept Breakdown

1. Both-End Operations

Unlike standard FIFO queues, Deques allow inserting (addFirst/addLast) and deleting (removeFirst/removeLast) from BOTH ends in O(1) time.

2. Queue + Stack Hybrid

A Deque can function as a FIFO Queue (insert Rear, remove Front) or a LIFO Stack (insert Front, remove Front) depending on which methods you invoke!

3. Real-World Power

Used for Undo/Redo buffers in code editors, browser history, and Sliding Window Maximum algorithms in algorithmic interviews.

📦 What is the First-In, First-Out (FIFO) Rule?

A Queue is a linear data structure operating under the FIFO (First-In, First-Out) principle. The first item inserted into the queue is guaranteed to be the first item removed. Think of a physical line of people waiting for a bus—the person who arrived first gets on the bus first!

Queue Flow Diagram
REAR (Enqueue ➡️) [Pkg #3] [Pkg #2] [Pkg #1] ➡️ FRONT (Dequeue)
Package #1 arrived first, so Package #1 MUST be shipped first!
JavaScript Implementation Standard Queue 
class FifoQueue {
  constructor() {
    this.elements = [];
  }
  // Enqueue: Add to back (O(1))
  enqueue(item) {
    this.elements.push(item);
  }
  // Dequeue: Remove from front (O(1) amortized or O(N) naive)
  dequeue() {
    return this.elements.shift();
  }
}

🎟️ Queue Operations & Boundary Safety

In fixed-capacity queues (like arrays with limited memory), operations must handle boundary conditions to prevent crashes and memory corruption:

⚠️ Overflow Exception

Occurs when calling Enqueue() on a queue that has reached maximum capacity (size === capacity).

⚠️ Underflow Exception

Occurs when calling Dequeue() on an empty queue (size === 0).

🔍 Peek() / Front() Operation

Peek() returns the element at the FRONT pointer without removing it. It runs in O(1) constant time because no elements are shifted.

🚦 Common Queue Variants

Standard queues can be modified to optimize memory usage or handle priority scheduling:

🔄 1. Circular Queue (Ring Buffer)

Solves the problem of wasted front slots after dequeuing. Uses modulo arithmetic to wrap rear back to index 0:

rear = (rear + 1) % Capacity;

🚨 2. Priority Queue

Each element has a priority level. High-priority items jump ahead of lower-priority items, overriding standard arrival order.

  • Hospital Triage: ER ambulances served first.
  • OS Process Scheduling: Interrupts take precedence.
  • Data Structure: Implemented via Binary Heaps ($O(\log N)$).

🚂 What is a Double-Ended Queue (Deque)?

A Deque (pronounced "deck") is a generalized linear data structure that supports inserting and removing elements from BOTH the FRONT and REAR pointers in O(1) constant time.

Double-Ended Flow Diagram
⬅️ FRONT (addFirst / removeFirst) ➡️ [Train #1] [Train #2] [Train #3] ⬅️ REAR (addLast / removeLast) ➡️
Carriages can enter or exit from the LEFT (FRONT) or RIGHT (REAR) gates!
1. addFirst(item)

Inserts element at the FRONT (Left) of the Deque. Time: O(1)

2. addLast(item)

Inserts element at the REAR (Right) of the Deque. Time: O(1)

3. removeFirst()

Removes and returns element from FRONT. Time: O(1)

4. removeLast()

Removes and returns element from REAR. Time: O(1)

Standard Queue REAR only FRONT only FIFO (First In, First Out)
Stack TOP only TOP only LIFO (Last In, First Out)
Deque FRONT or REAR FRONT or REAR Flexible (Both FIFO & LIFO)
JavaScript & Python Implementations Constant Time O(1) Both Ends 
// JavaScript (Doubly-Linked List or Array)
class Deque {
  constructor() { this.items = []; }
  addFirst(x) { this.items.unshift(x); }
  addLast(x)  { this.items.push(x); }
  removeFirst() { return this.items.shift(); }
  removeLast()  { return this.items.pop(); }
}

# Python (collections.deque - Doubly Linked List)
from collections import deque
d = deque()
d.appendleft("Carriage #1") # addFirst
d.append("Carriage #2")     # addLast
d.popleft()                 # removeFirst
d.pop()                     # removeLast
