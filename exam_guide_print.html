2. Queue Master (FIFO Realm) — Module Breakdown

A Queue is a linear data structure adhering to the First-In, First-Out (FIFO) principle: the first element inserted is the first one removed. Insertion happens at the REAR (Enqueue) and deletion occurs at the FRONT (Dequeue). Both operations operate in O(1) constant time.

Level 1: The FIFO Factory (Conveyor Belt)Level 1

Analogy: Industrial conveyor belt dispatching shipping packages.

Mechanism: Packages are added to the rear and dispatched from the front. Clicking non-front packages triggers a FIFO Violation Modal, reinforcing that intermediate random extraction is forbidden in queues.

Level 2: Theme Park Cashier (Linear Array Queue & False Overflow)Level 2

Capacity: Fixed static array with MAX = 5.

Boundary Conditions:

  • Queue Overflow: When rear == MAX - 1 and an enqueue operation is attempted.
  • Queue Underflow: When the queue is empty (front == -1 or front > rear) and dequeue is attempted.
Crucial Exam Topic: The False Overflow Phenomenon
In a standard linear array queue, dequeuing elements shifts the front pointer forward, leaving empty memory slots at the beginning. When rear == MAX - 1, no new items can be enqueued even if previous slots are empty. This is known as False Overflow (or memory wastage), which circular queues solve.
Level 3: Traffic Control & Emergency Room (Queue Variants)Level 3

Level 3 contrasts three major queue paradigms:

  1. Standard Linear Queue: Cars lined up at a one-way traffic light.
  2. Circular Queue: Solves False Overflow via Modulo Arithmetic: 
    rear = (rear + 1) % MAX;   // Wrap-around Enqueue
front = (front + 1) % MAX; // Wrap-around Dequeue
Full Condition: (rear + 1) % MAX == front
Empty Condition: front == -1
  3. Priority Queue: Elements have priority ranks (High: 🚑 Ambulance, Med: 🚌 City Bus, Low: 🚗 Sedan). Dequeue always extracts the highest priority element first, overriding strict arrival time.
Level 4: Train Switchyard (Double-Ended Queue / Deque)Level 4

A generalized linear list allowing insertion and deletion from both ends:

  • addFirst() & addLast() (Push Front / Push Rear)
  • removeFirst() & removeLast() (Pop Front / Pop Rear)

CS Variants: Input-Restricted Deque (insertion at one end, deletion at both) and Output-Restricted Deque (deletion at one end, insertion at both).

Level 5: Queue Trivia ArcadeLevel 5

Interactive 5-question viva test assessing FIFO terminology, modulo math, error conditions, and time complexities with heart lives and sound effects.

3. Stack Master (LIFO Realm) — Module Breakdown

A Stack is a linear data structure following the Last-In, First-Out (LIFO) principle: the most recently inserted element is always the first one to be removed. All insertions and deletions take place at a single end called TOP. All core operations run in O(1) constant time.

Level 1: The LIFO Cafeteria (Core Stack Fundamentals)Level 1

Analogy: Spring-loaded cafeteria plate dispenser.

Boundary Conditions:

  • Stack Overflow: top >= MAX - 1 (Array mode MAX = 6).
  • Stack Underflow: top == -1.
  • LIFO Violation: Clicking lower plates triggers an alert explaining that middle plates cannot be accessed directly without popping the top elements first.
Level 2: Polish Notation & Postfix LabLevel 2

Sub-Module A (Postfix Expression Evaluator):

  • Scan tokens left to right. Operands are pushed to the stack.
  • When an operator is encountered, pop B then A, compute A op B, and push result back.
  • Example: "2 3 1 * + 9 -" → 3 × 1 = 3 → 2 + 3 = 5 → 5 - 9 = -4. Result: -4.

Sub-Module B (Infix to Postfix Shunting-Yard Converter):

  • Precedence rules: ^ (exponent) > * / > + -.
  • Parentheses handling: ( is pushed; ) pops operators to output until ( is reached.
Level 3: Syntax Sentinel (Balanced Parentheses & Brackets)Level 3

Validates matching brackets for (), {}, []. Scans string left to right; pushes opening brackets; for closing brackets, pops and verifies matching pair. Detects premature underflow, type mismatch, and unclosed brackets. Features a live execution trace table.

Level 4: Monotonic Mountain (Next & Previous Greater Element)Level 4

Reduces finding Next Greater Element (NGE) from $O(N^2)$ brute force to $O(N)$ linear time using a Monotonic Decreasing Stack. Elements smaller than current are popped because they cannot be the next greater for any element to the left.

Level 5: Base & String TransformerLevel 5
  • String Reversal: Pushing characters to stack and popping them reverses the sequence in $O(N)$ time.
  • Radix Converter: Repeatedly divides decimal $N$ by target base $B$, pushes remainder $N \pmod B$, then pops from MSB to LSB.
Level 6: Dynamic Heap & Call Stack RecursionLevel 6
  • Linked List Stack: Nodes [info | next*] dynamically allocated via malloc(); eliminates fixed array overflow limits.
  • Call Stack Recursion: Visualizes factorial(4). Pushes activation frames during recursive calls ($n=4 \to n=3 \to n=2 \to n=1$), then unwinds returning calculated values on base case.
Level 7: Stack Arcade Boss Quiz & CheatsheetLevel 7

8-question comprehensive boss quiz testing theoretical and practical stack knowledge with celebratory confetti and formula cheatsheet.

4. Top 25 Data Structure Viva Questions & Answers

Q1: Fundamental difference between Stack and Queue?
A Stack is a LIFO (Last-In, First-Out) structure where insertions and deletions happen at a single end (TOP). A Queue is a FIFO (First-In, First-Out) structure where insertions occur at the REAR and deletions occur at the FRONT.
Q2: What are Stack Overflow and Underflow conditions?
Overflow occurs when pushing to a full stack (top >= MAX - 1 in 0-indexed array). Underflow occurs when popping from an empty stack (top == -1).
Q3: What is "False Overflow" in a Linear Queue?
In a linear queue, when items are dequeued, front moves forward leaving empty slots at the start. If rear == MAX - 1, further enqueuing fails even though unused memory exists. Solved by Circular Queues.
Q4: Circular Queue Full and Empty conditions?
Empty: front == -1. Full: (rear + 1) % MAX == front. Modulo arithmetic wraps pointers around to reuse vacated memory.
Q5: Time complexity of Push, Pop, Enqueue, and Dequeue?
All four operations run in O(1) constant time because elements are accessed directly via index pointers without element shifting.
Q6: Why convert Infix expressions to Postfix?
Infix requires precedence rules and parentheses. Postfix (Reverse Polish) eliminates parentheses and operator ambiguity, allowing compilers to evaluate expressions in a single $O(N)$ linear pass.
Q7: How to evaluate a Postfix expression with a Stack?
Scan left to right. Push operands. For operator op, pop $B = \text{pop}()$, $A = \text{pop}()$, compute $A \text{ op } B$, and push result back. Note operand order: $A - B$ and $A / B$.
Q8: How does balanced bracket validation work?
Push opening brackets ( { [. For closing brackets, check if stack is empty (premature underflow) or top doesn't match (type mismatch). At end of string, stack must be completely empty.
Q9: What is a Monotonic Stack and its complexity for Next Greater Element?
A stack maintained in strictly sorted order. For NGE, a monotonic decreasing stack scans right-to-left, popping smaller elements, reducing complexity from $O(N^2)$ brute force to $O(N)$ linear time.
Q10: What is a Double-Ended Queue (Deque)?
A queue allowing insertion and deletion at both ends: insertFront(), insertRear(), deleteFront(), deleteRear().
Q11: Input-Restricted vs. Output-Restricted Deque?
Input-restricted allows insertion at only one end, but deletion at both. Output-restricted allows deletion at only one end, but insertion at both.
Q12: How is a Priority Queue implemented efficiently?
Most efficiently implemented via a Binary Heap (Min-Heap / Max-Heap) with $O(\log N)$ enqueue and $O(\log N)$ dequeue. Unsorted arrays require $O(N)$ dequeue.
Q13: Array Stack vs. Linked List Stack?
Array stack has fixed size, no pointer memory overhead, and cache locality. Linked stack has dynamic sizing (no overflow), but consumes extra memory for next* pointers.
Q14: How does recursion relate to the Call Stack?
Each recursive call pushes an Activation Record (stack frame with parameters, local variables, and return address). When the base case triggers, frames pop off (unwinding). Infinite recursion triggers Stack Overflow.
Q15: How to convert Decimal to Binary using a Stack?
Divide decimal number by 2 repeatedly. Push remainder (N % 2) onto stack. Update N = N / 2 until 0. Pop stack: popped bits yield the binary number from MSB to LSB.
Q16: How to implement a Queue using two Stacks?
Use Stack1 for enqueue ($O(1)$ push). For dequeue: if Stack2 is empty, pop all elements from Stack1 into Stack2 (reversing order to FIFO), then pop from Stack2. Amortized $O(1)$ time.
Q17: How to implement a Stack using two Queues?
For push(x): enqueue $x$ to empty Q2, dequeue all elements from Q1 and enqueue into Q2, then swap names of Q1 and Q2. Pop is then $O(1)$ dequeue from Q1.
Q18: What is Prefix notation for (A + B) * C?
Prefix: * + A B C. Postfix: A B + C *.
Q19: How many elements can be stored in a circular queue of size N?
At most $N - 1$ elements if one empty slot is reserved to differentiate between full ((rear+1)%N == front) and empty (front == -1).
Q20: Difference between peek() and pop()?
peek() inspects the top element without removing it (pointer unchanged). pop() returns the top element and removes it (decrements top).
Q21: Name 4 real-world applications of Stacks.
1. Undo/Redo operations (Ctrl+Z). 2. Browser Back/Forward navigation. 3. Compiler syntax parsing and expression evaluation. 4. Function call stack memory management.
Q22: Name 4 real-world applications of Queues.
1. CPU process scheduling (Round Robin). 2. Printer print job spooling. 3. Breadth-First Search (BFS) graph traversal. 4. Async message queues (Kafka, RabbitMQ).
Q23: Why use Web Audio API instead of audio files?
Web Audio synthesizes frequencies mathematically in-browser via oscillators. It eliminates network lag, prevents 404 missing asset errors, requires zero bandwidth, and operates completely offline.
Q24: Space complexity of Array Stack vs. Linked Stack?
Array Stack: $O(MAX)$ pre-allocated space. Linked Stack: $O(K)$ space where $K$ is active elements, plus 8 bytes pointer overhead per node.
Q25: What live demonstrations can you show the examiner?
1. Stack Overflow: push 6 plates, attempt 7th to show overflow alert. 2. LIFO / FIFO Violation: click lower plate or rear package to show violation alert. 3. Circular Queue: show rear wrapping around index 4 to 0. 4. Postfix Evaluation: step through "2 3 1 * + 9 -".
